📌 CODEBOT – AI Powered Resume Matcher

CODEBOT is a frontend-based AI-inspired web application designed to automate resume analysis and job role matching. The application allows users to upload resumes in PDF format, extracts key candidate information, and evaluates how well the candidate matches various predefined job roles.

🚀 Features

Resume upload and PDF parsing using PDF.js

Automatic extraction of:

Name

Email

Phone number

Skills

Education

Experience

Role-based job dataset using JSON

Skill matching and percentage calculation

Visual role-matching results using progress bars

Clean, modern, and responsive UI

Fully client-side (HTML, CSS, JavaScript)

🛠 Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

PDF.js

🎯 Use Case

This project demonstrates how AI-inspired parsing and matching techniques can simplify recruitment workflows by quickly analyzing resumes and identifying suitable job roles.
